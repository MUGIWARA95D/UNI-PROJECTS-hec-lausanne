# HEC Lausanne: university projects

Three graded projects from my BSc in Management at HEC Lausanne (University of Lausanne), 2025-2026.
Each folder contains the deliverable (paper, model or deck) and the code or workbook behind it.

| # | Project | Course (grade) | Tools | Type |
|---|---|---|---|---|
| 01 | [AT&T vs Verizon: margin and investment analysis](01-financial-statement-analysis-att-verizon/) | Financial Statement Analysis & Reporting (5.0/6) | Excel, PowerPoint, Python (python-pptx) | Individual |
| 02 | [Can oil-market volatility predict U.S. equity volatility?](02-financial-econometrics-oil-vix/) | Financial Econometrics (5.0/6) | Python (pandas, statsmodels, fredapi) | Group |
| 03 | [Does appreciation of the Swiss franc affect Swiss gold exports?](03-empirical-research-chf-gold-exports/) | Empirical Research in Management & Economics (5.5/6) | Python (pandas, linearmodels, yfinance) | Group of 6 |

Grades are on the Swiss scale (6 = maximum, 4 = pass).

Author: Hugo Waldmeier. Related work: [SAINHE](https://github.com/MUGIWARA95D/sainhe-v4), a financial-analysis platform built from primary filings.
